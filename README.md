# Свой VPN

Личный VPN через HostVDS для Android и Windows. Движок AmneziaWG встроен в приложение.

## Скачать

- [Android 1.0.2 — APK](https://github.com/shifuuu3050ti-debug/svoy-vpn/releases/latest/download/SvoyVPN-Android.apk)
- [Windows x64 — EXE](https://github.com/shifuuu3050ti-debug/svoy-vpn/releases/latest/download/SvoyVPN.exe)
- [Исходники проекта — ZIP](https://github.com/shifuuu3050ti-debug/svoy-vpn/releases/latest/download/SvoyVPN-source.zip)
- [Описание релиза и контрольные суммы](https://github.com/shifuuu3050ti-debug/svoy-vpn/releases/latest)

## Android

1. Установите APK поверх предыдущей версии.
2. При первом запуске откройте **Ввести код доступа**, вставьте личный код и нажмите **Активировать**. Если профиль уже активирован, переходите сразу к подключению.
3. Нажмите круглую кнопку и подтвердите запрос Android на подключение VPN.

Настройки HostVDS зашифрованы в APK. Код передаётся отдельно. В меню **Приложения без VPN** можно найти приложения по названию и выбрать, какие будут выходить в интернет напрямую.

## Windows

Запустите EXE, активируйте личный профиль для ПК и нажмите кнопку подключения.
